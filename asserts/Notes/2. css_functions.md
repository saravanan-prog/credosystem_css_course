
# CSS Functions

A CSS function is a special instruction that CSS uses to calculate, modify, or generate a value.


#### 1. ➗  calc() Function

Used to perform dynamic calculations in CSS.

✅ Syntax

```
 width: calc(100% - 50px);
 ```

🔹 Example
```
.container {
  width: calc(100% - 200px);
}
```
###  2. min() — Choose the smallest

```
.item {
    width: min(90%, 500px);
}
```
### 3. max() — Choose the largest

```
.item {
    padding: max(20px, 5vw);
}
```

### 📏 4. clamp() Function

- Used for responsive sizing with min + preferred + max values.

✅ Syntax

```
 clamp(min, preferred, max)

 ```

🔹 Example

```
   font-size: clamp(14px, 2vw, 24px);
```

### 👉 Means:

- Minimum = 14px
- Flexible = 2vw
- Maximum = 24px

### 💡 Real use
```
h1 {
  font-size: clamp(20px, 5vw, 50px);
}
```

👉 Text scales smoothly across devices

### 🔥 Combine all three
```
:root {
  --base-size: 16px;
}

h1 {
  font-size: clamp(
    var(--base-size),
    calc(2vw + var(--base-size)),
    40px
  );
}
```
