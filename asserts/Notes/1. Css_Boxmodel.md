# CSS Box Model
#### ✅ Simple Structure

```
      Margin
        ↓
      Border
        ↓
      Padding
        ↓
      Content
```

#### 1. Margin
- Margin is the space outside the border of an element.
- It creates distance between elements.
```
div {
  margin: 20px;
}
```
- There will be 20px space outside the element on all sides.
You can also set individually:
```
margin-top: 10px;
margin-right: 20px;
margin-bottom: 10px;
margin-left: 20px;
```
##### Shortcut:-  margin : TBLR

    
    margin: 10px 20px;
    margin: 10px 10px 20px 20px;


### 2. Border
- Border is the line around the element, between margin and padding.
- Example:
```
div {
  border: 2px solid black;
}
```
#### Parts of border:

- width → thickness
- style → solid, dashed, dotted
- color

#### Example : You can also set individually
```
border-width: 3px;
border-style: dashed;
border-color: red;
```

### 3. Padding

- Padding is the space inside the border, between the content and border.
- Example:
```
div {
  padding: 20px;
}
```
#### Meaning:
- Content will have 20px space from the border.
- Example - Individual sides:
```
padding-top: 10px;
padding-right: 20px;
padding-bottom: 10px;
padding-left: 20px;
```
