# Background

#### Background Image
- This property adds an image as a background.
- Example:
```
body {
  background-image: url("image.jpg");
}
```
#### Background Repeat
- Controls how the background image repeats.
- Example:
```
body {
  background-repeat: no-repeat;
}
```
| Value     | Meaning             |
| --------- | ------------------- |
| repeat    | repeat image        |
| no-repeat | show only once      |
| repeat-x  | repeat horizontally |
| repeat-y  | repeat vertically   |

#### Background Position
- Controls where the background image appears.
- Example:
```
body {
  background-position: center;
}
```
#### Background Size
- Controls the size of the background image.
- Example:
```
body {
  background-size: cover;
}
```
| Value   | Meaning                  |
| ------- | ------------------------ |
| cover   | image covers entire area |
| contain | image fits inside area   |
| auto    | default size             |

```
body {
  background-image: url("bg.jpg");
  background-size: cover;
}
```
⭐ Complete Example
```
body {
  background-color: lightgray;
  background-image: url("background.jpg");
  background-repeat: no-repeat;
  background-position: center;
  background-size: cover;
  background-attachment: fixed;
}
```
