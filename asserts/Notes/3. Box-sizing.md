# 📦 What is box-sizing?
👉 It controls how the total size of a box is calculated

# 🎯 Two Types

### 1️⃣ content-box (Default)

- 👉 Width/height = only content
- 👉 Padding + border = added outside

Example:
```
div {
  width: 200px;
  padding: 20px;
  border: 5px solid red;
}

    🧠 Actual size:
    Content = 200px
    Padding = 20 + 20 = 40px
    Border = 5 + 5 = 10px

    👉 Total width = 250px ❌ (bigger than expected)

```


# 2️⃣ border-box (Best practice 🔥)

👉 Width includes:

        content + padding + border

Example:
```
div {
  width: 200px;
  padding: 20px;
  border: 5px solid red;
  box-sizing: border-box;
}

🧠 Actual size:

    👉 Total width = 200px only ✅
    👉 Content shrinks automatically




```
