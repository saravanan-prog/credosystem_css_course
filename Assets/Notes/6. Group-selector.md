# Group Selector

- The group selector applies the same style to multiple elements.
- Use a comma `,`.

###### Types of Group Selector

   - child selector
   - desandent selector
   - Adjacent selector
   - general 

Example
```
h1, h2, p {
  color: purple;
}
```

HTML:

```
<h1>Title</h1>
<h2>Subtitle</h2>
<p>Paragraph</p>
```

✅ All become purple.
