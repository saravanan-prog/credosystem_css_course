# 📝 1. Font Family


👉 Defines which font style to use

```
p {
  font-family: Arial, sans-serif;
}
```
💡 If Arial not available → uses sans-serif


# 🔠 2. Font Size

👉 Controls text size

```
p {
  font-size: 20px;
}
```

📦 Bigger number → bigger text


# 💪 3. Font Weight

👉 Controls thickness (boldness)

```
p {
  font-weight: bold;
}

OR

p {
  font-weight: 700;
}

```

💡 Values:

- 400 = normal
- 700 = bold
