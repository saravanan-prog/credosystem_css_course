# 📦 1. Width

👉 width defines the horizontal size of an element’s content area (by default).

✅ Example:
```
div {
  width: 200px;
}

This means the content inside the `<div>` will be 200px wide.

```


### 📦 1. min-width (Minimum Width)

When you don’t want the element to become too small

✅ Example:
```
.box {
  min-width: 150px;
}
```

👉 Screen small width won’t go below 150px

### 📦 2. max-width (Maximum Width)

When you don’t want the element to become too wide

✅ Example:
```
.box {
  max-width: 800px;
}


```

👉 On large screens → stops at 800px







# 📏 2. Height

height defines the vertical size of an element’s content area.

```
div {
  height: 100px;
}
```
👉 The content area will be 100px tall.


### 📦 1. min-height (Minimum Height)
When you want a box to always have some height, even if content is small.

✅ Example:
```
.box {
  min-height: 200px;
}
```
👉 Even if no content → box still 200px tall

### 📦 2. max-height (Maximum Height)
When you want to limit height and control overflow.

✅ Example:
```
.box {
  max-height: 200px;
  overflow: auto;
}




```
