## Pseudo-class-selector
Pseudo-selector is used to select an HTML element based on its state or position.

```
:hover       → mouse over
:focus       → selected/focused
:active      → clicking
:first-child → first
:last-child  → last
:nth-child() → position
:checked     → checkbox/radio selected

```

## Pseudo-element

It styles a specific part of an element or creates generated content.

```
p::first-line { }
p::before { }
p::after { }
```
