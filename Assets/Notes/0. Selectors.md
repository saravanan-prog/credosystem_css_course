## CSS Selector?
A CSS selector is used to select HTML elements that you want to style.

## Types of CSS Selectors

There are 8 important types you should know:

- Universal Selector → *
- Element/Tag Selector → p
- Class Selector → .class
- ID Selector → #id
- Grouping Selector → h1, p
- Descendant Selector → div p
- Child Selector → div > p
- Attribute Selector → input[type="text"]

Also important
- Pseudo-class Selector → button:hover
- Pseudo-element Selector → p::before
