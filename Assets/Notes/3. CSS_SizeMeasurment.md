# 1️⃣ Absolute Units (fixed, don’t change)

These units are fixed, meaning they don’t depend on parent or screen size.

✅ Example:
```
div {
  width: 200px;   /* fixed width */
  height: 100px;  /* fixed height */
  font-size: 16px; 
}

````



| Unit   | Meaning                     | Use Case                              |
| ------ | --------------------------- | ------------------------------------- |
| **px** | Pixel → 1 dot on the screen | Font size, borders, small UI elements |
| **cm** | Centimeter                  | Rarely used in screen design          |
| **mm** | Millimeter                  | Mostly print                          |
| **in** | Inches                      | Mostly print                          |
| **pt** | Points (1pt = 1/72 inch)    | Print                                 |
| **pc** | Picas (1pc = 12pt)          | Print                                 |


# 2️⃣ Relative Units (flexible, responsive)

These depend on parent, root, or screen size, very important for modern websites.


```
div {
  width: 50%;    /* half of parent container */
  font-size: 2em;  /* 2× parent font size */
  height: 50vh;   /* half of screen height */
}

    If parent width = 400px → 50% = 200px

    If root font-size = 16px → 2rem = 32px

    Viewport width = 1200px → 50vw = 600px

```

📦 Example with Relative Units

| Unit     | What it’s relative to           | Example                                  |
| -------- | ------------------------------- | ---------------------------------------- |
| **%**    | Percentage of parent            | `width: 50%;` → half of parent width     |
| **em**   | Parent element’s font size      | `font-size: 2em;` → 2 × parent font size |
| **rem**  | Root element (`html`) font size | `font-size: 2rem;` → 2 × root font size  |
| **vw**   | 1% of viewport width            | `width: 50vw;` → 50% of screen width     |
| **vh**   | 1% of viewport height           | `height: 50vh;` → 50% of screen height   |
| **vmin** | Smaller of vw or vh             | Responsive minimum size                  |
| **vmax** | Larger of vw or vh              | Responsive maximum size                  |

## 3️⃣ Key Concept to Remember

px → fixed, exact size ✅

% → depends on parent → flexible ✅

em → relative to parent font → text scaling ✅

rem → relative to root font → consistent scaling ✅

vw / vh → relative to screen → responsive layouts ✅


## 4️⃣ Friend Tip

 Use px only for borders, icons, precise UI

Use %, em, rem, vw, vh for responsive layouts
