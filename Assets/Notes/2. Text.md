# ↔️ 1. Text Alignment

👉 Controls horizontal alignment

```
p {
  text-align: center;
}
```

💡 Options:
- left
- center
- right

# ✏️ 2. Text Decoration

👉 Adds/removes lines

```
    p {
        text-decoration: underline;
    }
```

💡 Options:

- underline
- overline
- line-through
- none

# 📏 3. Line Height

👉 Space between lines

```
p {
  line-height: 1.5;
}
```

📦 More value → more space → easy to read

# 🔤 4. Letter Spacing

👉 Space between letters

```
p {
  letter-spacing: 2px;
}
```
📦 More spacing → letters spread out


# 🔤 5. text-transform

👉 Space between letters

```
p {
  text-transform: upperacase;   /* lower case */
}
```





📦 Full Example

```
<p class="text">
  Hi I am Saravanan learning CSS
</p>

.text {
  font-family: Arial, sans-serif;
  font-size: 20px;
  font-weight: bold;
  text-align: center;
  text-decoration: underline;
  line-height: 1.5;
  letter-spacing: 2px;
}

```
