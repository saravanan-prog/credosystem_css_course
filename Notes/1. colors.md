# 1️⃣ Color Values

- CSS allows you to define colors in different ways.
- The most common color formats are:

```
Color name
HEX
RGB
```
### Color Name
- blue
- green
- yellow
- black
- white
- gray

```
p {
  color: red;
}
```

### HEX Color
- HEX (Hexadecimal) color codes start with #.
- Format:
```
#RRGGBB
```
- Example:
```
p {
  color: #ff0000;
}
```
### RGB Color
- RGB stands for Red, Green, Blue.
- Each value ranges from 0 to 255.

Example:

```
p {
  color: rgb(255, 0, 0);
}
```

| Color | RGB          |
| ----- | ------------ |
| Red   | rgb(255,0,0) |
| Green | rgb(0,255,0) |
| Blue  | rgb(0,0,255) |

#  2️⃣ Background Color
- This property sets the background color of an element.
- Example:
```
body {
  background-color: lightblue;
}
```
```
div {
  background-color: yellow;
}
```
