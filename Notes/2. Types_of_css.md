# Types of CSS
 There are three ways to apply CSS to HTML:

- Inline CSS
- Internal CSS
- External CSS

### 1️⃣ Inline CSS
CSS is written inside the HTML tag using the style attribute.
```
<h1 style="color: red;">Hello World</h1> 
```
<h1 style="color: red;">Hello World</h1>

### 2️⃣ Internal CSS
CSS is written inside the `<style>` tag in the `<head>` section.
Example:
```
<!DOCTYPE html>
<html>
<head>
<style>
h1 {
  color: green;
}
</style>
</head>

<body>
<h1>Hello World</h1>
</body>
</html>
```
<!DOCTYPE html>
<html>
<head>
<style>
h1 {
  color: green;
}
</style>
</head>

<body>
<h1>Hello World</h1>
</body>
</html>

3️⃣ External CSS ⭐

-   CSS is written in a separate .css file and linked to HTML.
- HTML file:
```
<link rel="stylesheet" href="style.css">
```
 CSS file (style.css):
```
h1 {
  color: blue;
}
```
✅ Best method for real projects.
