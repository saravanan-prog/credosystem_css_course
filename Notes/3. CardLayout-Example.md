# 🧱 2. Card Layout (Responsive Grid using Flexbox)

✅ HTML

```
<div class="cards">
  <div class="card">Card 1</div>
  <div class="card">Card 2</div>
  <div class="card">Card 3</div>
</div>
```

🎨 CSS

```
.cards {
  display: flex;
  gap: 20px;
  flex-wrap: wrap;
}


.card {
  flex: 1 1 200px;
  padding: 20px;
  background: #f4f4f4;
  border-radius: 10px;
}

```

#### 💡 What’s happening:

- flex-wrap: wrap → moves cards to next line
- flex: 1 1 200px → responsive sizing
- gap → spacing

👉 Works like a grid without using Grid!
