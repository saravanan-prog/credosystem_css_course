# 🧭 1. Responsive Navbar (Flexbox)

✅ HTML

```
<nav class="navbar">
  <div class="logo">MySite</div>
  <ul class="menu">
    <li>Home</li>
    <li>About</li>
    <li>Contact</li>
  </ul>
</nav>
```
🎨 CSS

```
.navbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: 15px 20px;
  background: #333;
  color: white;
}

.menu {
  display: flex;
  gap: 20px;
  list-style: none;
}
```

### 💡 What’s happening:

- display: flex → horizontal layout
- space-between → logo left, menu right
- align-items: center → vertical center
