# ➗  calc() Function

Used to perform dynamic calculations in CSS.

✅ Syntax

```
 width: calc(100% - 50px);
 ```

🔹 Example
```
.container {
  width: calc(100% - 200px);
}
```

👉 Full width minus sidebar

🔹 With variables
```
:root {
  --gap: 20px;
}

.box {
  width: calc(100% - var(--gap));
}
```
#### ⚠️ Important

```
👉 Always keep spaces around operators

calc(100% - 20px) ✅
calc(100%-20px) ❌
```


# 📏 3. clamp() Function

- Used for responsive sizing with min + preferred + max values.

✅ Syntax

```
 clamp(min, preferred, max)

 ```

🔹 Example

```
   font-size: clamp(14px, 2vw, 24px);
```

### 👉 Means:

- Minimum = 14px
- Flexible = 2vw
- Maximum = 24px

### 💡 Real use
```
h1 {
  font-size: clamp(20px, 5vw, 50px);
}
```

👉 Text scales smoothly across devices

### 🔥 Combine all three
```
:root {
  --base-size: 16px;
}

h1 {
  font-size: clamp(
    var(--base-size),
    calc(2vw + var(--base-size)),
    40px
  );
}
```
