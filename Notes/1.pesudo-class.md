# 🎯 What are Pseudo-classes?

 - They start with : and apply styles when something happens to an element.

✅ Example
```
.button {
  background: gray;
}

.button:hover {
  background: green;
}

 👉 Button changes color when hovered
```



## ⌨️ 2. :focus

Applies when an element is focused (clicked or selected via keyboard like Tab).

✅ Example

```
input:focus {
  border: 2px solid blue;
}

👉 Input box highlights when clicked or tabbed into

```

## 🔥 Combined Example

```
a {
  color: black;
}

a:hover {
  color: red;
}

a:focus {
  outline: 2px solid orange;
}
```
