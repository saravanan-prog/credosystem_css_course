# What is CSS

CSS (Cascading Style Sheets) is used to style and design HTML webpages.
 It controls things like:


- Colors
- Fonts
- Layout
- Spacing
- Animations

CSS Syntax:
``` 
selector  {
  property: value;
}
```
Example:
``` 
<h1> Hello world </h1>

h1 {
  color: blue;
}
```
Explanation:
| Part    | Meaning  |
| ------- | -------- |
| `h1`     | selector |
| `color` | property |
| `red`   | value    |

## CSS Comments
Syntax:
```
/* This is a CSS comment */
```
Example:
```
/* Change heading color */

h1 {
  color: blue;
}
```
