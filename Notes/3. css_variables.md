# 🎯 1. CSS Variables (Custom Properties)

- Used to store reusable values.

✅ Syntax

```
    :root {
        --main-color: blue;
    }
```
👉 -- defines a variable

🔹 Use variable

h1 {
  color: var(--main-color);
}

Example

```
:root {
  --primary: #3498db;
  --padding: 10px;
}



.box {
  background: var(--primary);
  padding: var(--padding);
}

```
## 🚀 Why use it?
- Easy to update styles
- Reusable
- Great for themes
