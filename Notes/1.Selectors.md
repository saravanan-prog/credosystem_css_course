## 1️⃣ Element Selector
The element selector selects HTML elements by their tag name.
Example:
```
p {
  color: blue;
}
```

HTML:

```<p>Hello World</p>
<p>This is CSS</p>
```

✅ All `<p>` elements become blue.

## 2️⃣ Class Selector

- The class selector selects elements using the class attribute.
- It is written using a dot (.).

Example
```
.text {
  color: red;
}
```

HTML:

```
<p class="text">Hello</p>
<p class="text">Welcome</p>
```

✅ Both paragraphs become red.

## 3️⃣ ID Selector

- The ID selector selects an element using the id attribute.
- It is written using #.

Example
```
#title {
  color: green;
}
```

HTML:

```
<h1 id="title">My Website</h1>
```

✅ Only that element becomes green.

⚠️ An ID should be unique on the page.

# 4️⃣ Universal Selector

The universal selector (*) selects all elements.

Example
```
* {
  margin: 0;
  padding: 0;
}
```

✅ Applies styles to every element on the page.

Often used for CSS reset.

# 5️⃣ Group Selector

- The group selector applies the same style to multiple elements.
- Use a comma `,`.

###### Types of Group Selector
   - child selector
   - desandent selector
   - Adjacent selector
   - general 

Example
```
h1, h2, p {
  color: purple;
}
```

HTML:

```
<h1>Title</h1>
<h2>Subtitle</h2>
<p>Paragraph</p>
```

✅ All become purple.

# 6️⃣ Attribute Selector

The attribute selector selects elements based on HTML attributes.

Example
```
input[type="text"] {
  border: 2px solid blue;
}
```

HTML:

```
<input type="text">
<input type="password">
```

✅ Only the text input gets the style.
